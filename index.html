Как пользоваться генератором вариантов

Генератор позволяет собирать тренировочные варианты по заданиям 1–20 ЕГЭ профильного уровня. Можно настроить вариант вручную или за один клик получить полный случайный вариант, а затем скачать интерактивную версию, файл для печати, ключи, презентацию или игру.

1. Быстрые полные варианты

В верхней панели укажите количество полных вариантов от 1 до 40 и нажмите «🎲 Сгенерировать полные варианты». В каждый вариант автоматически попадёт по одному заданию каждого номера 1–20.

  • для заданий 1–13 в случайный вариант попадают только основные задачи; дополнительные задачи первой части не используются;
  • для заданий 14–20 используется полная текущая база;
  • прототипы каждого номера сначала проходят без повторов, а затем перемешиваются для следующего круга; задачи внутри прототипов также перебираются по очереди;
  • после сборки нескольких вариантов появляется переключатель, с помощью которого можно просматривать любой готовый вариант;
  • кнопка «🎲 Заменить» возле отдельного задания меняет только его, остальные задания остаются прежними.

Кнопка «🔑 Ключи (Ответы)» создаёт общую таблицу ответов ко всей пачке. Если отдельное задание было заменено, в таблице будет его обновлённый ответ.

2. Ручная сборка варианта

Если нужен не полный случайный вариант, а собственный набор, задайте количество задач у нужных номеров.

Количество можно указать двумя способами:

  • нажимать кнопки + и −;
  • вписать нужное количество вручную.

Если нужно выбрать не весь номер задания, а только конкретные типы, нажмите «Настроить». В открывшемся окне можно отметить только нужные прототипы.

Над заданиями второй части расположен отдельный заголовок «Задания с развёрнутым ответом». К ним относятся задания 14–20.

3. Аналоги и разборы

Если включён пункт «Добавить разборы заданий», в интерактивном варианте можно открыть разбор и перейти к аналогичным задачам для тренировки.

Разбор можно свернуть кнопкой «Скрыть», при этом задачи для самостоятельной тренировки остаются на экране.

4. Черновик

В интерактивном варианте есть встроенный черновик. Обычные задания, задачи для отработки и аналоги используют один и тот же набор инструментов и одинаковую логику рисования.

В заданиях второй части видимый размер окна черновика остаётся компактным, а рабочая область внутри имеет высоту ровно в 3 раза больше и прокручивается. Это даёт место для длинного решения без тяжёлого холста, который может тормозить.

В черновике доступны ручка, маркер, ластик, отмена и возврат действия, фигуры, выбор цвета и толщины линии, а также очистка поля. Записи сохраняются во время работы с вариантом.

5. Настройте оформление

В разделе оформления можно выбрать:

  • вариант без стикеров;
  • готовые наборы стикеров;
  • свой пакет стикеров;
  • готовый фон;
  • свой фон.

Если выбран «Свой пакет», можно загрузить собственные картинки-стикеры. Генератор автоматически уменьшит их до подходящего размера.

Стикеры появляются в интерактивном варианте и в файле для печати. Фон используется в интерактивном варианте; можно выбрать готовый фон или загрузить свой.

6. Дополнительные параметры

Мгновенная проверка при решении. Ученик может сразу ввести ответ и увидеть результат проверки.

Показывать верный ответ при ошибке. При неверном ответе система дополнительно показывает правильный ответ.

Упорядочить задания. Если пункт включён, задачи выводятся в заданном порядке; если выключен, выбранные задачи могут перемешиваться.

Подпись учителя. Можно добавить подпись учителя в готовый вариант.

Таймер. Можно задать ограничение по времени. Значение 0 работает как обычный секундомер и показывает, сколько времени ученик затратил на выполнение.

7. Сгенерируйте вариант

Для ручного набора после выбора заданий и настроек нажмите «Сгенерировать выбранные задания». Для полного набора из 1–20 заданий укажите количество (1–40) и используйте верхнюю кнопку «🎲 Сгенерировать полные варианты».

8. Скачайте нужный формат

После генерации доступны несколько форматов.

💻 Интерактивный вариант. Ученик решает задания прямо в браузере. Доступны проверка, черновики, разборы и тренировка на аналогах — в зависимости от выбранных настроек.

🖨️ Файл для печати (PDF). Выберите компактную горизонтальную печать A4 в две колонки или формат с полями для решения. Все полные варианты печатаются подряд, после них добавляются общие ключи. Сайт скачивает готовый PDF. Дата, адрес файла и заголовок браузера в него не добавляются.

🔑 Ключи (Ответы). Для пачки полных вариантов создаётся таблица ответов ко всем вариантам; для ручной подборки — отдельные ответы.

🎬 Презентация. Вариант можно оформить как презентацию: выбрать готовый дизайн или использовать собственное оформление.

🎮 Игра. Задания можно использовать в игровых форматах для урока, повторения или командной работы.

9. Игровые режимы

Башня знаний — ученик решает задания и продвигается по башне.

Битва с боссом — задания проходят в формате игры с противником.

Мотивационное послание — изображение разбивается на части пазла, которые открываются за верные ответы. Можно выбрать готовую картинку или загрузить свою.

10. Как сохранить и передать вариант

Скачанный файл можно отправить ученику, открыть на компьютере или разместить на своей платформе. Интерактивный вариант и игровые файлы открываются в браузере.

Если HTML-файл некорректно прикрепляется или не отправляется через мессенджер, например ВКонтакте, добавьте его в ZIP-архив и отправьте ученику архив. После скачивания ученику достаточно распаковать архив и открыть HTML-файл в браузере.
